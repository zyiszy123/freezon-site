iPhone 與 iPad 免雲端私密相簿：將私密照片保存在裝置上

將選取的照片、影片與原況照片加密保存在裝置上，成功匯入後即可離線查看。

English 简体中文 繁體中文 日本語 한국어 Español (Latinoamérica) Português (Brasil)

你可以將私密照片、影片與原況照片保存在 iPhone 上，無須連上網路或擁有 App 帳號即可開啟。「定格私密相簿」會直接在你的裝置上加密從 Apple「照片」App 中選取的內容，成功匯入後即可離線查看。

從匯入到開啟飛航模式

首先，在 Apple「照片」App 中選取你想匯入的照片、影片或原況照片。由於並非所有原始檔都已下載到裝置上，請等待匯入完成；這些內容會在裝置上加密，只有成功匯入後才能離線開啟。Apple「照片」App 中的副本會保留，除非你確認移除。

在「定格私密相簿」中，日常（Everyday）與私密（Private）相簿使用各自獨立的密碼，日常相簿也可以選擇使用 Face ID 或 Touch ID。舉例來說，你將 Apple「照片」App 中的一張照片、一段影片和一張原況照片匯入私密相簿，其他照片則放在已啟用 Face ID 的日常相簿中。匯入完成後，你可以開啟飛航模式，無須帳號或網路連線即可開啟 App，透過 Face ID 或日常相簿的密碼進入日常相簿，再用私密相簿的獨立密碼解鎖，查看已匯入的內容。成功匯入的媒體雖然可以離線開啟，但並非所有 App 功能都能離線運作。

離線存取檢查清單

在需要依靠離線存取之前，先快速檢查一下，確保已匯入的媒體都能正常開啟。花一點時間測試，可以提早發現尚未完成的匯入或存取問題。

  • 確認匯入完成：檢查每一張選取的照片、每一段影片和每一張原況照片是否都已從 Apple「照片」App 匯入完成，不要直接假設原始檔早已下載到裝置上。
  • 測試飛航模式：開啟飛航模式，檢查已匯入的內容能否在 App 內開啟，同時記得並非所有 App 功能都能離線運作。
  • 檢查相簿存取方式：確認自己記得日常與私密相簿各自的密碼，並了解日常相簿是否設定了可選用的 Face ID 或 Touch ID。
  • 決定是否保留 Apple「照片」App 中的副本：確認匯入的內容可以離線開啟後，再決定是否保留原本的副本。除非你確認移除，否則它們會繼續保留在 Apple「照片」App 中。

給 iPad 使用者的一點說明

「定格私密相簿」同時支援 iPad 與 iPhone，在兩種裝置上都會對選取的媒體進行本機加密。不過，每次安裝都有各自獨立的照片圖庫：圖庫不會在不同安裝之間自動同步，因此你在 iPhone 上匯入的內容，與在 iPad 上匯入的內容彼此獨立。

備份如何影響 App 內的儲存

選擇備份不會改變媒體在 App 內的儲存方式。建立備份時，App 會將一個加密檔案寫入你在「檔案」App 中選定的檔案夾，也可以選擇使用 iCloud Drive；已匯入的內容則仍然加密保存在裝置上的 App 內。請妥善保管備份檔案及其對應的復原碼，因為還原時可以使用這份檔案和復原碼。
