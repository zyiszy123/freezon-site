새 iPhone으로 비공개 사진을 백업하고 전송하는 방법

Freezon의 온디바이스 암호화 백업과 보안 복구 코드를 사용하여 비공개 사진을 새 iPhone으로 안전하게 이전하는 방법입니다.

비공개 사진을 백업하여 새 iPhone으로 전송하려면 현재 기기의 Freezon에서 암호화된 백업을 생성하고, 일치하는 보안 복구 코드를 보관한 다음, 새 휴대폰의 앨범 설정 과정에서 해당 백업을 복원하세요. Freezon은 iPhone 및 iPad용 온디바이스 암호화 사진 보관함으로 작동하여 미디어를 외부 서버에 업로드하거나 백그라운드에서 기기 간 앨범을 동기화하지 않고 사용자의 제어하에 로컬에서 안전하게 보호합니다.

지금 새 iPhone으로 기기를 변경하든 향후 손쉬운 데이터 이전을 보장하는 비공개 사진 보관함을 선택하든, Freezon의 백업 워크플로는 미디어에 대한 완전한 소유권을 제공합니다. 휴대가 가능한 암호화된 백업 파일을 통해 마이그레이션을 관리함으로써 완전한 개인정보 보호를 유지하면서 라이브러리를 새 기기로 원활하게 이전할 수 있습니다.

시작하기 전에 준비할 두 가지

마이그레이션 과정을 시작하기 전에 다음 두 가지 항목이 준비되어 있는지 확인하세요.

Freezon에서 Daily 앨범과 Private 앨범을 모두 사용하는 경우 두 앨범을 별도의 보관함으로 취급해야 합니다. 각 앨범은 고유한 독립된 백업 파일과 해당 복구 코드를 유지합니다.

  • 접근 가능한 백업 파일(.pvb): 사진과 동영상이 포함된 암호화된 아카이브입니다. iCloud Drive의 폴더와 같이 새 기기에서 시스템 파일 앱을 통해 접근할 수 있는 위치에 저장합니다.
  • 일치하는 보안 복구 코드: 해당 아카이브를 잠금 해제하고 복원하려면 앨범과 일치하는 보안 복구 코드가 필요합니다. 이 코드를 비밀번호 관리자나 서면 기록에 안전하게 보관하세요.

백업 생성 및 저장

현재 iPhone 또는 iPad에서 백업을 생성하려면 Freezon을 열고 마이그레이션할 앨범으로 이동하세요. 해당 앨범 내에서 암호화된 백업 기능을 열면 Freezon에서 시스템 파일 인터페이스를 사용하여 내보낼 위치를 선택하도록 안내합니다.

iCloud Drive의 지정된 폴더와 같이 새 기기에서 쉽게 접근할 수 있는 디렉터리를 선택하세요. .pvb 파일을 iCloud Drive에 저장하면 파일 앱을 통해 여러 기기에서 해당 아카이브에 접근할 수 있습니다. 파일 저장과 앨범 동기화의 차이점을 이해하면 도움이 됩니다. iCloud Drive는 정적인 .pvb 파일을 단순히 보관하고 전송하는 역할만 하며, Freezon은 앨범에 대한 자동 클라우드 동기화를 실행하지 않습니다.

앱에서 백업 완료를 확인할 때까지 Freezon 내에 머무르세요. 프로세스가 완료되면 앨범과 일치하는 보안 복구 코드가 있는지 확인합니다. 새 기기를 설정할 때 사용할 수 있도록 이 코드를 정확하게 기록하여 잘 보관해 두세요.

새 iPhone에서 사진 복원하기

새 iPhone이 준비되면 다음 단계를 진행하여 복원을 완료하세요.

  • 1. 파일 앱에서 파일 사용 가능 여부 확인: 새 iPhone에서 시스템 파일 앱을 열고 iCloud Drive 디렉터리와 같이 선택한 백업 폴더로 이동합니다. .pvb 파일이 보이고, 완전히 다운로드되었으며, 접근 가능한 상태인지 확인하세요.
  • 2. Freezon에서 앨범 설정 시작: 새 iPhone에서 Freezon을 엽니다. 초기 앨범 구성 중에 암호화된 백업에서 복원하는 옵션을 선택하세요.
  • 3. 파일 선택 및 복구 코드 입력: 파일 선택기를 사용하여 .pvb 백업 파일을 선택한 다음 기존 기기에서 저장해 둔 일치하는 보안 복구 코드를 입력하세요.
  • 4. 새 앨범 비밀번호 설정: Freezon이 앨범 콘텐츠를 복원하면 새 휴대폰에서 해당 앨범에 사용할 새로운 일상 잠금 해제 비밀번호를 지정하세요.

이중 앨범 독립 검증

Freezon은 명확한 개인정보 보호 경계를 유지하기 위해 Daily 앨범과 Private 앨범을 분리합니다. 미디어가 두 앨범에 나뉘어 있다면 각 앨범의 백업 및 복원 단계를 별도로 수행하세요.

각 앨범을 독립적인 단계로 처리하면 비밀번호, 개인정보 보호 경계 및 보관함 설정이 완전히 분리된 상태로 유지됩니다.

  • Daily 앨범에 대한 .pvb 백업 파일을 내보내고 보안 복구 코드를 저장합니다.
  • Private 앨범에 대한 별도의 .pvb 백업 파일을 내보내고 고유한 보안 복구 코드를 저장합니다.
  • 새 iPhone에서 해당 파일과 일치하는 복구 코드를 사용하여 각 앨범을 개별적으로 복원합니다.

기존 기기를 지우기 전 콘텐츠 확인

이전 기기를 지우거나 재설정하거나 보상 판매하기 전에 미디어가 새 iPhone에 올바르게 복원되었는지 확인하세요.

사진과 동영상이 정상적으로 열리는 것을 확인한 후 이전 기기를 초기화하거나 폐기하는 단계를 진행할 수 있습니다.

  • 사진 로딩 확인: Freezon에서 복원된 앨범을 열고 사진을 둘러보며 섬네일이 제대로 로드되고 원본 해상도 이미지가 깨끗하게 열리는지 확인합니다.
  • 최근 추가된 항목 점검: 마이그레이션 전에 가장 최근에 가져온 사진과 파일을 검토하여 최신 미디어가 백업에 포함되었는지 확인합니다.
  • 동영상 재생 테스트: 한두 개의 동영상을 처음부터 끝까지 재생하여 끊김 없이 매끄럽게 재생되는지 확인합니다.
  • 두 앨범 모두 확인: Daily 앨범과 Private 앨범을 모두 마이그레이션한 경우 각 보관함을 개별적으로 열어 두 앨범 모두에서 이러한 확인 과정을 완료합니다.

자주 묻는 질문

새 iPhone에서 백업 파일을 찾을 수 없으면 어떻게 해야 하나요?

Freezon에서 설정을 시작하기 전에 새 iPhone에서 시스템 파일 앱을 직접 여세요. iCloud Drive 폴더 등 백업을 저장한 위치로 이동하여 .pvb 파일이 표시되는지 확인합니다. 파일에 클라우드 다운로드 아이콘이 표시되면 탭하여 파일을 로컬로 다운로드해야 Freezon에서 복원 중에 열 수 있습니다.

복구 코드 대신 일상 앨범 비밀번호로 앨범을 복원할 수 있나요?

아닙니다. 일반 앨범 잠금 해제 비밀번호는 해당 특정 기기에서의 일상적인 접근 용도로만 사용되며, 내보낸 아카이브를 복호화할 수 없습니다. 앨범을 복원하려면 해당 .pvb 백업 파일과 일치하는 보안 복구 코드가 필요합니다. 이전 기기에서 백업을 생성할 때 저장한 복구 코드를 찾아 설정 중에 입력하세요.

마지막 백업을 생성한 후에 사진을 추가한 경우 어떻게 해야 하나요?

백업을 생성한 후 새로운 사진이나 동영상을 가져온 경우, 새 휴대폰에서 설정을 완료하기 전에 이전 기기에서 백업을 업데이트하세요. 이전 iPhone에서 Freezon을 열고 암호화된 백업 기능을 다시 실행한 후 앱 내에서 백업 완료 확인이 나타날 때까지 기다린 다음 일치하는 보안 복구 코드를 준비하세요. 그런 다음 새 기기에서 이 업데이트된 .pvb 파일을 복원할 수 있습니다.
