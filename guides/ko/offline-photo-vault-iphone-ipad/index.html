iPhone·iPad용 오프라인 사진 잠금 앱: 개인 사진을 기기에 보관하세요

선택한 사진과 동영상, Live Photo를 기기에 암호화해 보관하고, 가져오기가 정상적으로 끝나면 오프라인으로 확인하세요.

English 简体中文 繁體中文 日本語 한국어 Español (Latinoamérica) Português (Brasil)

개인 사진과 동영상, Live Photo를 iPhone에 저장하고 인터넷 연결이나 앱 계정 없이 열 수 있습니다. ‘Freezon’은 Apple 사진 앱에서 선택한 항목을 기기에서 직접 암호화하며, 정상적으로 가져온 항목은 오프라인으로 볼 수 있습니다.

가져오기부터 비행기 모드까지

먼저 Apple 사진 앱에서 가져올 사진과 동영상, Live Photo를 선택합니다. Apple 사진 앱의 원본이 모두 기기에 다운로드되어 있는 것은 아니므로 가져오기가 끝날 때까지 기다리세요. 항목은 기기에서 암호화되며, 정상적으로 가져온 뒤에만 오프라인으로 열 수 있습니다. Apple 사진 앱에 있는 사본은 삭제를 확인하기 전까지 그대로 남습니다.

Freezon의 일상(Everyday) 앨범과 비공개(Private) 앨범은 서로 다른 비밀번호를 사용하며, 일상 앨범에서는 Face ID 또는 Touch ID 사용 여부를 선택할 수 있습니다. 예를 들어 Apple 사진 앱에서 사진 한 장, 동영상 하나, Live Photo 한 장을 비공개 앨범으로 가져오고, 다른 사진은 Face ID를 켠 일상 앨범에 보관한다고 가정해 보세요. 가져오기가 끝나면 비행기 모드를 켜고 계정이나 인터넷 연결 없이 앱을 열 수 있습니다. Face ID 또는 일상 앨범의 비밀번호로 일상 앨범에 들어가고, 비공개 앨범은 별도의 비밀번호로 잠금을 풀어 가져온 항목을 볼 수 있습니다. 정상적으로 가져온 미디어는 인터넷 없이 열 수 있지만, 앱의 모든 기능이 오프라인으로 작동하는 것은 아닙니다.

오프라인 접근 확인 체크리스트

오프라인 접근이 필요한 상황에 대비해, 가져온 미디어가 예상대로 열리는지 간단히 확인해 보세요. 잠깐 시간을 내어 설정을 테스트하면 미완료된 가져오기나 접근 문제를 미리 발견할 수 있습니다.

  • 가져오기 완료 확인: 원본이 이미 다운로드되어 있다고 가정하지 말고, 선택한 사진과 동영상, Live Photo를 모두 Apple 사진 앱에서 가져왔는지 확인하세요.
  • 비행기 모드에서 테스트: 비행기 모드를 켜고 가져온 항목이 앱 안에서 열리는지 확인하세요. 앱의 모든 기능이 오프라인으로 작동하는 것은 아니라는 점도 기억하세요.
  • 앨범 접근 확인: 일상 앨범과 비공개 앨범의 서로 다른 비밀번호를 알고 있는지 확인하세요. 일상 앨범에 선택적으로 설정한 Face ID 또는 Touch ID도 확인하세요.
  • Apple 사진 앱의 사본 보관 여부 결정: 가져온 항목이 오프라인으로 열리는 것을 확인한 뒤 Apple 사진 앱의 사본을 남길지 결정하세요. 삭제를 확인하기 전까지 사본은 그대로 유지됩니다.

iPad 사용자를 위한 안내

Freezon은 iPhone뿐 아니라 iPad에서도 사용할 수 있으며, 선택한 미디어에 동일한 기기 내 암호화를 적용합니다. 다만 설치된 앱마다 별도의 보관함을 사용합니다. 사진 보관함은 각 설치본 사이에서 자동으로 동기화되지 않으므로 iPhone에서 가져온 항목과 iPad에서 가져온 항목은 서로 분리되어 있습니다.

백업이 앱 내 저장 방식에 미치는 영향

백업을 선택해도 앱 내 미디어의 저장 방식은 바뀌지 않습니다. 백업을 만들면 앱은 파일 앱에서 선택한 폴더에 암호화된 파일을 저장하며, 원하면 iCloud Drive를 사용할 수도 있습니다. 가져온 항목은 계속 기기의 앱 안에 암호화된 상태로 남습니다. 백업 파일과 해당 파일의 복구 코드는 복원에 사용할 수 있으므로 안전하게 보관하세요.
